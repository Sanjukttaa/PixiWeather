PixiWeather 🌤

PixiWeather is a retro-inspired weather web app that turns simple weather updates into a cozy pixel-art experience. Inspired by old arcade games and nostalgic pixel visuals, the project combines creative frontend design with smooth animations, dynamic themes, and colorful backgrounds to make checking the weather more fun and interactive.

The app changes its appearance based on weather conditions, creating different moods for sunny, rainy, snowy, or cloudy days. Built using HTML, CSS, and JavaScript, PixiWeather focuses on a lightweight, responsive, and visually appealing user experience across desktop and mobile devices.

✨ Features

🎮 Retro pixel-art UI using the Press Start 2P font
🌤 Dynamic weather-based themes
☁ Animated pixel-style backgrounds
📱 Responsive design for all devices
⚡ Fast and lightweight frontend project
🎨 Cozy and colorful visual aesthetics

🚀 Purpose

This project was created to explore frontend development, animations, responsive layouts, and creative UI design while experimenting with retro gaming aesthetics and pixel-art inspired visuals.

💙 Inspiration

Inspired by retro arcade games, pixel-art worlds, and cozy weather aesthetics.
